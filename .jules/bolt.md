## 2026-06-18 - [React.memo and Inline Closures]
**Learning:** In Next.js App Router applications, wrapping list components like `PropertyCard` in `React.memo` is ineffective if parent components pass inline closure functions as props (e.g., `onFavoriteChange={(next) => handleChange(property, next)}`). The inline function creates a new reference on every parent render, completely breaking the memoization and causing the child to unnecessarily re-render anyway.
**Action:** Always refactor parent callback props passed to memoized children to use `useCallback`. To eliminate inline closures that capture loop variables, modify the child component's prop signature to emit its identifier (e.g., `id`) back to the stable parent callback, allowing the parent to identify the item without relying on closure scope.
