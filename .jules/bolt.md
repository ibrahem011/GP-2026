## 2024-05-03 - Parallelize File Uploads
**Learning:** Sequential I/O operations (like looping through multiple image uploads via `for...of`) are a significant bottleneck when handling user file uploads. Using `Promise.all` allows parallel execution of independent network calls, providing measurable speedups. For rollback tasks (like deleting uploaded images on subsequent errors), `Promise.allSettled` is safer than `Promise.all` as it ensures all deletion operations are attempted even if one fails.
**Action:** Always prefer `Promise.all` for parallelizing independent async I/O actions (e.g., storage uploads/deletions) and use `Promise.allSettled` when executing a batch of cleanup/rollback tasks where partial failure should not prevent the rest of the operations from being attempted.
