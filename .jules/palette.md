## 2024-05-20 - Icon-Only Material Symbols Accessibility Pattern
**Learning:** Found a widespread accessibility issue where icon-only buttons using `material-symbols-outlined` ligatures lack `aria-label`s. This causes screen readers to misinterpret the buttons or literally read the ligature text (e.g., "notifications", "logout"), which is especially problematic in an application localized in Arabic. Additionally, the buttons often lack focus-visible outlines for keyboard users.
**Action:** Always add an explicit Arabic `aria-label` to the parent `<button>` (e.g., `aria-label="الإشعارات"`), apply `aria-hidden="true"` to the inner icon `<span>` to hide the ligature from assistive technologies, and add `focus-visible:ring-2 focus-visible:outline-none` for proper keyboard focus indicators.
