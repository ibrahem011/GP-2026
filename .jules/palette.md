## 2024-05-18 - Accessibility for Icon-Only Buttons in RTL Apps
**Learning:** In RTL (Right-to-Left) Arabic applications, icon-only buttons (like back arrows, support agents, and more options) must have localized Arabic `aria-label` and `title` attributes (e.g., "الرجوع", "الدعم") to ensure screen readers correctly interpret the action in the appropriate language context. Furthermore, the internal icon element (like a Material Symbol `span`) must use `aria-hidden="true"` to prevent redundant screen reader announcements, and the button itself must include keyboard accessibility classes (`focus-visible:outline-none focus-visible:ring-2`).
**Action:** When adding or modifying icon-only buttons, always explicitly define `aria-label`, `title`, keyboard focus states, and `aria-hidden` on the inner icon, ensuring the labels are localized to match the app's default language.
