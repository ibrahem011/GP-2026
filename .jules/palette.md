## 2024-05-18 - Added Accessibility and Keyboard Focus to Theme Toggle
**Learning:** In Next.js with React 18, applying accessibility enhancements to dynamic components like a ThemeToggle (which relies on `next-themes` and a `mounted` check) required carefully bypassing `react-hooks/set-state-in-effect` during hydration to avoid lint errors without causing hydration mismatches. Additionally, in an RTL Arabic application, ensuring tooltips and `aria-label`s are translated is critical, and placing `aria-hidden="true"` on inner decorative icons (like Google Material Symbols) is essential to prevent screen readers from reading the ligature literal (e.g. "dark_mode") out loud.
**Action:** When working on UI components, always verify tooltips/ARIA labels are localized for RTL, ensure keyboard-focused visual states are present using `focus-visible`, and apply `aria-hidden` to purely decorative icons. Handle hydration correctly and apply the appropriate ESLint disable rules strictly for the intended line.
