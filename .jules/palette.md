## 2024-04-28 - Toggleable View Buttons Accessibility
**Learning:** Using `aria-pressed` correctly indicates the active state of toggleable buttons (like list/grid view modes) to screen readers. Relying solely on visual cues (like background colors or shadow changes) leaves visually impaired users unaware of which view is currently active. Adding `aria-label` ensures the button's action is understood even when the content is purely visual (like icons). Adding `focus-visible:ring-2 focus-visible:outline-none` improves visibility for keyboard users. Adding `aria-hidden="true"` to inner icon elements prevents screen readers from redundantly announcing the icon's SVG details or generic text.
**Action:** When implementing custom toggleable elements, particularly icon-only buttons, ensure `aria-pressed` is dynamically bound to the active state, provide a descriptive `aria-label`, ensure clear focus states, and hide the decorative/functional inner icons from screen readers using `aria-hidden="true"`.
