## 2026-03-15 - Missing ARIA Labels on Custom Increment/Decrement Controls
**Learning:** Custom UI controls for numeric filters (like bedrooms and bathrooms) in this app use icon-only buttons (+/-) without native `<input type="number">`. These were missing `aria-label` attributes, rendering them completely opaque to screen readers, especially in the Right-To-Left (RTL) Arabic context.
**Action:** Always verify icon-only interactive elements in custom filter components and explicitly add Arabic `aria-label`s to provide context (e.g., 'زيادة عدد غرف النوم' for incrementing bedrooms).
## 2026-06-18 - Ensure Arabic Localization and Proper Accessibility for Icon-Only Theme Toggles
**Learning:** When dealing with globally accessible UI elements like Theme Toggles in an RTL Arabic application, default English `aria-label`s (e.g., 'Switch to dark mode') are completely ineffective for screen reader users and break the application's localized context. Furthermore, Material Symbols ligatures (e.g., 'dark_mode') must be hidden using `aria-hidden='true'` to prevent screen readers from reading out the literal icon names when a proper label is already provided.
**Action:** Always verify that icon-only buttons like Theme Toggles have accurate Arabic `aria-label` and `title` attributes, include `aria-hidden='true'` on the raw text icon elements, and feature visible `focus-visible` rings for keyboard users.
