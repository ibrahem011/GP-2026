## 2025-04-09 - Accessible Icon-Only Buttons
**Learning:** In Arabic/bilingual applications, icon fonts like Material Symbols (`<span className="material-symbols-outlined">favorite</span>`) can be announced phonetically or incorrectly by screen readers ("favorite" instead of the Arabic equivalent).
**Action:** Always add `aria-hidden="true"` to the icon element itself and apply a descriptive, translated `aria-label` to the parent interactive `<button>` or `<a>` tag. Combine this with `focus-visible` classes (e.g., `focus-visible:ring-2 focus-visible:outline-none`) to ensure keyboard navigability.
