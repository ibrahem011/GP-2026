## 2024-03-20 - Adding explicit ARIA labeling for decorative Material Icons in Property Cards
**Learning:** Material icons using ligatures (e.g., `<span className="material-symbols-outlined">favorite</span>`) are read aloud by screen readers as their text content ("favorite", "bed", etc.) rather than their visual meaning. In the context of a highly visual UI component like PropertyCard, this results in confusing auditory experiences for screen reader users, especially in a right-to-left Arabic layout. Furthermore, interactive but icon-only buttons (like a favorite button) need dynamic `aria-label` values to announce state changes (added/removed) effectively.
**Action:** When implementing Material Symbols or similar ligature-based icon fonts, always append `aria-hidden="true"` to decorative instances to hide them from the accessibility tree. For icon-only interactive elements, ensure a descriptive, context-aware `aria-label` is applied to the interactive parent (e.g., `<button aria-label="أضف للمفضلة">...<span aria-hidden="true">favorite</span></button>`). Additionally, for "View Details" links, dynamically append the property title to the `aria-label` (e.g., "عرض تفاصيل [Title]") so users navigating via links list have complete context.
