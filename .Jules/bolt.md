## 2025-02-28 - Preserving Component Memoization with stable callbacks and useRef
**Learning:** When using React.memo() on list items (e.g., PropertyCard), passing an inline callback closure like `onFavoriteChange={(nextState) => handleFavoriteChange(property, nextState)}` from the parent defeats memoization entirely because the closure creates a new function reference on every parent render.
**Action:** Update the item component to pass back its own ID in the callback (`onFavoriteChange?: (id: string, nextState: boolean) => void`). In the parent, maintain a Map of items in a `useRef` synchronized via `useEffect`, and use a stable `useCallback` without closure dependencies that looks up the item using the ID from the `useRef`. This guarantees the callback reference remains stable, preserving the `React.memo` optimization.
