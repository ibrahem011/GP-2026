## 2025-02-27 - Stabilizing Callbacks for List Memoization
**Learning:** When optimizing list components with `React.memo`, passing inline functions that depend on the loop's item (like `(nextState) => handleChange(item, nextState)`) breaks the memoization because the function reference changes on every render. Relying solely on `useCallback` in the parent isn't enough if the callback needs access to the full item object from the list.
**Action:** Synchronize the list items into a `useRef` Map via `useEffect` (e.g., `propertiesRef.current.set(property.id, property)`). Then, update the item component to emit only its primitive ID alongside the change. The parent's stable `useCallback` can use this ID to look up the full item object from the ref map without breaking the list's memoization or causing unnecessary re-renders.
